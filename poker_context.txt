# Design Principles

- Game rules belong to **game-func.js**.
- Game flow belongs to **PokerEngine**.
- UI rendering belongs to **render.js**.
- DOM creation belongs to **appender.js**.
- UI notifications belong to **utils.js**.
- `PokerEngine.gameState` is the primary game state container.
- `renderCardsTo()` is the canonical card rendering function.
- `getBestCombination()` is the canonical 7-card hand evaluator.
- `evaluateFiveCards()` is the canonical 5-card evaluator.
- `dealCards()` is the canonical dealing function.
- `tasov()` is responsible for deck creation and shuffle.

---

# Project Goal

Develop a modular Texas Hold'em engine that cleanly separates:

- game state
- poker mechanics
- rendering
- UI
- utility functions

to allow future expansion with new gameplay modes, AI improvements, and DLC features without major architectural changes.
